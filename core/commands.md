# ⚡ Comandos de Three.js 3D Web Agent Skill (`three-js-agent-skills`)

| Comando | Acción | Descripción |
|---|---|---|
| `$threejs` | Bootstrap | Inicializa la skill y carga contexto Three.js. |
| `$threejs:audit` | Auditoría | Audita render loop, memoria de texturas y geometría WebGL. |
| `$learnskill three-js-agent-skills [propuesta]` | Aprendizaje | Registrar propuesta de mejora específica para `three-js-agent-skills` en `overview/learning.md` |
| `$revlearnskill` | Revisión | Clasificar e inspeccionar propuestas de aprendizaje acumuladas en `overview/learning.md` |
